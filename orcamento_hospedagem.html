Orçamento de hospedagem e domínio

Comparamos 3 opções de hospedagem e 3 opções de domínio para publicar o EcoVida.

Premissas do projeto

O site é estático (HTML, CSS e JavaScript no navegador), sem backend nem banco de dados. Isso reduz bastante a necessidade de recursos de servidor e permite opções gratuitas ou de baixo custo.

Atenção: os valores abaixo são faixas estimadas para comparação acadêmica, sujeitas a promoções e reajustes. Confirme os preços nos sites oficiais antes de decidir.

Escolha recomendada

Hospedagem A (GitHub Pages) + domínio 1 (.com.br)

  • Custo total estimado: ≈ R$ 40 por ano (apenas o domínio).
  • Adequação técnica: o site é estático, então não exige servidor com banco de dados.
  • Boas práticas: HTTPS incluso e histórico de versões com Git.
  • Evolução: se o projeto passar a precisar de backend (por exemplo, salvar o progresso dos usuários), migramos para a opção B ou C sem mudar o domínio.
